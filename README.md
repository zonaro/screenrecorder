# Screen Recorder Pro

Extensão Chrome para gravação de tela com facecam, edição de vídeo e exportação para Google Drive, OneDrive e YouTube.

## Funcionalidades

- **Gravação de tela** com áudio do sistema e microfone
- **Facecam** via Picture-in-Picture (gravada junto ou como janela flutuante)
- **Editor de vídeo** com timeline multi-pista, cortes, overlays, legendas e pan/zoom
- **Exportação** para MP4 ou WebM com configurações de qualidade
- **Upload** direto para Google Drive, OneDrive e YouTube
- **Biblioteca de gravações** — todas as gravações são salvas automaticamente e podem ser baixadas, editadas, reenviadas ou excluídas a qualquer momento
